# ol1n.now — CLAUDE.md

## Overview

Static app store for distributing own apps (Windows/macOS/Linux/mobile). Hosted on GitHub Pages at `olin.now`. No backend — download buttons link directly to GitHub release assets. Built from Markdown app metadata + Makefile pipeline.

## Commands

```bash
make fetch        # Fetch latest GitHub release artifacts per app → dist/downloads/<slug>.tsv
make screenshots  # Resize raw screenshots + transcode videos → dist/screenshots/<slug>/
make build        # Generate static site → dist/
make deploy       # Publish dist/ to gh-pages branch
make import-skins # (authoring, local only) Re-encode Kiran skin galleries → apps/kirian/skins/
```

Tooling: `make screenshots` needs **ImageMagick** (`magick`); **ffmpeg** is only
required when `raw/` contains videos (transcodes to web mp4 + generates a poster).
`make fetch` needs `gh` (authenticated) + `jq`.
`make import-skins` needs ImageMagick **with a WebP delegate** + ffmpeg + a local
Kiran checkout (`KIRAN_SRC`, defaults to `../Kiran`); it is never run on CI.

## Structure

```
apps/<slug>/
  meta.md              # YAML front-matter (name, repo, platforms, store links) + Markdown description
  screenshots/
    raw/<kind>/<platform>/   # Source screenshots (png/jpg) AND short videos (mp4/mov/webm/m4v)
                             # kind = desktop|mobile ; videos capped to 15s, transcoded to web mp4
  skins/               # Optional, committed, web-ready skin gallery (make import-skins)
    skins.tsv          #   id name year theme vessels bloom crt tint notes wiki pixelart
    assets.tsv         #   skin ord category file label meta1 meta2
    <skin_id>/<category>/*.{webp,m4a}

assets/                # Site-wide assets (CSS, fonts, icons)
scripts/               # Makefile helper scripts
templates/             # HTML/CSS templates for site generation

dist/                  # Built site (git-ignored)
  downloads/<slug>.tsv # Release artifact manifest (generated by make fetch)
  screenshots/<slug>/  # Resized screenshots (generated by make screenshots)
  skins/<slug>/        # Copy of apps/<slug>/skins/ (make build)

CNAME                  # olin.now (included in build for GitHub Pages custom domain)
```

## Skins gallery

Only `kirian` has one today. Source of truth is the game repo `lioilsources/Kiran`
(`SKINS.md`, `lib/services/skin_registry.dart`, `assets/skins/<id>/`);
`scripts/import-skins.sh` transcodes it to WebP + AAC (`.ogg` is unplayable in
Safari/iOS), buckets sprites into categories by filename, and writes the two TSV
manifests. `make build` only copies the result.

`build-site.sh` gates the whole feature on `dist/skins/<slug>/skins.tsv` existing,
so apps without skins render byte-identically to before. It emits a teaser section
on `<slug>.html` and a full explorer at `<slug>-skins.html` (skin picker + one panel
per skin, categories: preview, vessels, enemies, boss, asteroids, fx, ui, backgrounds,
sfx, music). A category with no manifest rows emits nothing at all — that is how the
`default` skin's empty `backgrounds/` is handled.

## App Catalog

Current apps (in `apps/`): djfy, doggiowars, doodlebugs, kindlify, kirian (Kiran), lexify,
mangaprompts, mirrorbooth, ol1nllm, orbitrontactics, poetrystream, swypekids.

All are standalone binaries except **doggiowars**, which is a Luanti (ex-Minetest) mod —
no per-platform executable, so it sets `artifacts: mod` (a platform-agnostic `.zip` bucket in
`fetch-artifacts.sh`, opt-in because that pattern would otherwise match the Flutter apps'
macOS/Windows zips) and carries a `contentdb:` link.

Everything is called DoggioWars now — repo, `mod.conf` `name`/`title`, the Luanti world, and
the store entry. The old name `aerowars` is fully gone as of `DoggioWars@v0.1.0`; renaming it
was a breaking change, because `name` is the namespace of every registered node, so worlds
saved under the old name load their blocks as unknown.

Note for install instructions: a mod folder does **not** have to match `name`. Luanti reads
`name` from `mod.conf` and, per its own docs, that works "even if the folder is wrongly
named".

## Adding a New App

1. Create `apps/<slug>/meta.md` with YAML front-matter
2. Add screenshots to `apps/<slug>/screenshots/raw/`
3. `make fetch` — pulls release manifest
4. `make screenshots` — resizes screenshots
5. `make build` — regenerates site
6. `make deploy` — publishes to GitHub Pages

## Deployment

- Branch `gh-pages` is the published branch
- `CNAME` file in build keeps custom domain `olin.now` active
- Cloudflare proxied (SSL mode Full) — no server needed
- Binary hosting: links to GitHub release URLs (repos must be public)
