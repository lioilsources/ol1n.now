tagline: 为 USB DAC 打造的比特完美播放器 — 文件、内存、ASIO，中间别无他物
---
Elfton Player 是一款 Windows 11 本地音乐播放器，只有一个目标：
送进 USB DAC 的采样，必须和文件里的一模一样。
信号路径是 **文件 → 解码器 → 内存 → ASIO → DAC**。没有音量调节，
没有均衡器，没有重采样，没有流媒体。音量请在解码器或
功放上调节。

### 功能

- **比特完美输出**，通过 ASIO 或独占模式的 WASAPI。曲目旁会显示整条链路
  （`FLAC 24/96k → 32-bit · bit-perfect`），一旦有任何东西改动信号，
  绿点就会熄灭。
- **从内存播放。** 整首曲目解码进内存，播放时硬盘不工作；下一首会提前载入，
  **无缝衔接**。
- **采样级精确的 A-B 循环**，循环点可按毫秒微调 —— 适合练习某段乐句，
  或对比录音中的两个位置。
- **按文件夹组织的曲库**：目录树和你硬盘上的一样，封面、搜索、播放队列、
  收藏、历史记录、M3U 播放列表、带 CUE 的单文件专辑、LRC 同步歌词。
- **FLAC、ALAC、WAV、AIFF、MP3、AAC、Ogg 和 DSD**（原生、DoP 或转换为 PCM）。
- **单声道 (L+R)/2** 是对信号唯一的改动，并且始终醒目标出。
- **L 和 R 按钮** 只让一只音箱发声，另一只静音。开启单声道时两边播放相同内容，
  坐在沙发上用手机就能立刻对比音响系统的左右两侧（线材、器件）；不开单声道时，
  只播放录音的左声道或右声道。
- **按曲目响度绘制的进度条** 横跨整个窗口宽度：安静的前奏一眼可见，
  点一下就能跳过。
- **每首曲目都有爱心**，专辑内可直接用“仅看收藏”筛选。
- **三种主题**：深色、纯黑和浅色。
- **手机遥控**：Elfton Remote 通过家庭网络扫描二维码配对，
  能做到电脑窗口能做的一切。

### 播放模式

可按需在播放时切换电源计划，关闭 USB 选择性暂停和核心停放，结束后全部恢复。
说实话：对于异步 USB DAC，时钟由解码器掌控，这些调整对声音没有可测量的影响。
它们都是可选的，每一项都会写入日志，而且没有一项是必需的。

借鉴自 Bug head 播放器的“仪式”也是如此，它们在设置里，默认关闭：
把音乐锁定在内存中、载入曲目后暂停片刻、随播放器一起启动你自己的辅助程序
（例如 MinorityClean）。MinorityClean 不包含在内。

### 现状

**0.2 版，预发布。** 第一个版本在一位听众的 Windows 11 上通过 ASIO
（Behringer UMC204HD 和 SMSL D200）运行：WAV 24/192 以 32 位 ASIO 输出，
没有转换、没有断音，手机遥控也正常。这是播放器自己对信号路径的报告；
目前还没有人采集输出并逐比特比对。0.2 的新功能已有测试覆盖，
但还没在 Windows 上运行过。截图来自第一个版本，
是用示例曲库的 macOS 开发版截取的 —— 上面还没有响度条和 L/R 切换。

Windows 版是一个 zip：解压后运行 `Elfton Player.exe`，或运行附带的
`install.ps1`，它会在开始菜单添加快捷方式。除此之外不会安装任何东西。
使用 ASIO 需要先安装解码器的驱动；没有驱动时播放器会提供 WASAPI。
手机遥控目前只有 Android 版（APK）；iOS 版代码已完成，但还没有公开版本。

引擎用 Go 编写，基于 FFmpeg（LGPL，动态链接），界面用 Flutter。
