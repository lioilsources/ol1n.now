---
tagline: USB DAC のためのビットパーフェクト・プレーヤー — ファイル、RAM、ASIO、その間には何もなし
---
Elfton Player は Windows 11 用のローカル音楽プレーヤーです。優先することはただひとつ、
ファイルに入っているサンプルをそのまま USB DAC に届けること。
信号経路は **ファイル → デコーダー → RAM → ASIO → DAC**。音量調整なし、
イコライザーなし、リサンプリングなし、ストリーミングなし。音量は
DAC かアンプで調整します。

### できること

- **ビットパーフェクト出力**：ASIO、または排他モードの WASAPI。曲の横に経路全体が
  表示され（`FLAC 24/96k → 32-bit · bit-perfect`）、信号に何かが手を加えた瞬間に
  緑のドットが消えます。
- **メモリからの再生。** 曲全体を RAM にデコードするので、再生中ディスクは動きません。
  次の曲も先読みされ、**ギャップレス**でつながります。
- **サンプル単位で正確な A-B リピート**。ポイントはミリ秒単位で調整でき、
  パッセージの練習や録音の 2 か所の聴き比べに使えます。
- **フォルダー単位のライブラリ**：ディスク上のディレクトリツリーそのまま、ジャケット、
  検索、キュー、お気に入り、履歴、M3U プレイリスト、CUE 付きの 1 ファイルアルバム、
  LRC による同期歌詞。
- **FLAC、ALAC、WAV、AIFF、MP3、AAC、Ogg、DSD**（ネイティブ、DoP、または PCM 変換）。
- **モノラル (L+R)/2** は信号に加える唯一の処理で、常にはっきり表示されます。
- **L ボタンと R ボタン**で片方のスピーカーだけを鳴らし、もう片方をミュートします。
  モノラルをオンにすると両方から同じ音が出るので、椅子に座ったままスマホで
  システムの左右（ケーブル、パーツ）をすぐに比べられます。モノラルなしなら、
  録音の左チャンネルだけ、または右チャンネルだけが鳴ります。
- **曲のラウドネスで描かれたシークバー**がウィンドウの幅いっぱいに表示されます。
  静かなイントロもひと目でわかり、ワンクリックで飛ばせます。
- **曲ごとのハート**と、アルバム内で使える「お気に入りのみ」フィルター。
- **3 つのテーマ**：ダーク、ブラック、ライト。
- **スマホがリモコンに**：Elfton Remote は QR コードで家庭内ネットワーク経由で
  ペアリングでき、PC のウィンドウと同じ操作ができます。

### 再生モード

必要に応じて、再生中は電源プランを切り替え、USB のセレクティブサスペンドと
コアパーキングをオフにし、終了後にすべて元に戻します。正直に言うと、非同期 USB DAC
ではクロックを握っているのは DAC なので、これらの調整に音への測定可能な効果は
ありません。どれも任意で、ひとつずつログに記録され、どれも必須ではありません。

Bug head プレーヤーから取り入れた「儀式」も同じです。設定にあり、初期状態では
オフになっています：音楽を RAM にロックする、曲の読み込み後に一時停止する、
独自の補助プログラム（たとえば MinorityClean）をプレーヤーと一緒に起動する。
MinorityClean は同梱されていません。

### 現状

**バージョン 0.2、プレリリース。** 最初のバージョンは、ひとりのリスナーの
Windows 11 環境で ASIO（Behringer UMC204HD と SMSL D200）を通して動作しました。
WAV 24/192 は変換なし・音切れなしの 32 ビット ASIO として出力され、
スマホからの操作も機能しています。これは信号経路についてのプレーヤー自身の
報告で、出力をキャプチャしてビット単位で比較した人はまだいません。0.2 の新機能は
テストでカバーされていますが、Windows ではまだ動かしていません。スクリーンショットは
最初のバージョンのもので、サンプルライブラリを使った macOS 向け開発ビルドから
撮影しています。ラウドネスのバーと L/R 切り替えはまだ写っていません。

Windows 版は zip です。展開して `Elfton Player.exe` を起動するか、同梱の
`install.ps1` を実行するとスタートメニューにショートカットが追加されます。
それ以外は何もインストールされません。ASIO を使うには DAC のドライバーが
インストールされている必要があり、ない場合は WASAPI が選べます。スマホ用
リモコンは今のところ Android（APK）のみです。iOS 版はコード上は完成していますが、
公開ビルドはありません。

エンジンは FFmpeg（LGPL、動的リンク）の上に Go で書かれ、UI は Flutter です。
