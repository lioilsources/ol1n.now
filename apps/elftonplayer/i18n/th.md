tagline: เครื่องเล่นแบบ bit-perfect สำหรับ USB DAC — ไฟล์, RAM, ASIO และไม่มีอะไรคั่นกลาง
---
Elfton Player คือเครื่องเล่นเพลงในเครื่องสำหรับ Windows 11 ที่มีเป้าหมายเดียว:
ให้แซมเปิลที่ไปถึง USB DAC ตรงกับที่อยู่ในไฟล์ทุกประการ
เส้นทางสัญญาณคือ **ไฟล์ → ตัวถอดรหัส → RAM → ASIO → DAC** ไม่มีปรับระดับเสียง
ไม่มีอีควอไลเซอร์ ไม่มีรีแซมเปิล ไม่มีสตรีมมิง ระดับเสียงให้ปรับที่
DAC หรือแอมป์

### ทำอะไรได้บ้าง

- **เอาต์พุตแบบ bit-perfect** ผ่าน ASIO หรือ WASAPI ในโหมดเอกสิทธิ์ ข้างเพลงจะแสดง
  ทั้งสายสัญญาณ (`FLAC 24/96k → 32-bit · bit-perfect`) และจุดสีเขียวจะดับทันที
  ที่มีอะไรก็ตามเข้าไปยุ่งกับสัญญาณ
- **เล่นจากหน่วยความจำ** ทั้งเพลงถูกถอดรหัสลง RAM ดิสก์จึงไม่ทำงานระหว่างเล่น
  เพลงถัดไปถูกโหลดไว้ล่วงหน้าและต่อกัน **ไร้ช่องว่าง**
- **ลูป A-B แม่นยำระดับแซมเปิล** เลื่อนจุดได้ทีละมิลลิวินาที — สำหรับซ้อมท่อนใดท่อนหนึ่ง
  หรือเปรียบเทียบสองตำแหน่งในงานบันทึกเสียง
- **คลังเพลงตามโฟลเดอร์**: ต้นไม้ไดเรกทอรีตามที่อยู่ในดิสก์ของคุณ ปกอัลบั้ม
  การค้นหา คิว รายการโปรด ประวัติ เพลย์ลิสต์ M3U อัลบั้มไฟล์เดียวพร้อม CUE
  เนื้อเพลงซิงก์จาก LRC
- **FLAC, ALAC, WAV, AIFF, MP3, AAC, Ogg และ DSD** (เนทีฟ, DoP หรือแปลงเป็น PCM)
- **โมโน (L+R)/2** เป็นการแตะต้องสัญญาณเพียงอย่างเดียว และมีป้ายบอกชัดเจนเสมอ
- **ปุ่ม L และ R** ให้ลำโพงดังข้างเดียวและปิดเสียงอีกข้าง เมื่อเปิดโมโน ทั้งสองข้าง
  เล่นเหมือนกัน จึงนั่งบนเก้าอี้แล้วใช้มือถือเทียบฝั่งซ้ายและขวาของชุดเครื่องเสียง
  (สายสัญญาณ อุปกรณ์) ได้ทันที ถ้าไม่เปิดโมโนจะได้ยินเฉพาะช่องซ้ายหรือเฉพาะช่องขวา
  ของงานบันทึกเสียง
- **แถบเลื่อนที่วาดเป็นความดังของเพลง** กว้างเต็มหน้าต่าง: อินโทรที่เงียบจะมองเห็นได้
  และข้ามได้ในคลิกเดียว
- **หัวใจที่เพลง** และตัวกรอง "เฉพาะรายการโปรด" ในอัลบั้มได้เลย
- **สามธีม**: มืด ดำ และสว่าง
- **รีโมตในมือถือ**: Elfton Remote จับคู่ด้วยคิวอาร์โค้ดผ่านเครือข่ายในบ้าน
  และทำได้ทุกอย่างเหมือนหน้าต่างบนคอมพิวเตอร์

### โหมดการเล่น

หากต้องการ ระหว่างเล่นจะสลับแผนการใช้พลังงาน ปิด USB selective suspend และ
core parking แล้วคืนค่าทั้งหมดเมื่อเล่นจบ พูดกันตรง ๆ: กับ USB DAC แบบอะซิงโครนัส
นาฬิกาอยู่ที่ DAC การปรับเหล่านี้จึงไม่มีผลต่อเสียงที่วัดได้ ทั้งหมดเป็นตัวเลือก
แต่ละอย่างถูกบันทึกลงล็อก และไม่มีอย่างใดจำเป็น

เช่นเดียวกับ "พิธีกรรม" ที่รับมาจากเครื่องเล่น Bug head ซึ่งอยู่ในการตั้งค่าและ
ปิดไว้โดยค่าเริ่มต้น: ล็อกเพลงไว้ใน RAM หยุดชั่วครู่หลังโหลดเพลง และเปิดโปรแกรมเสริม
ของคุณเอง (เช่น MinorityClean) พร้อมกับเครื่องเล่น MinorityClean ไม่ได้รวมมาด้วย

### สถานะ

**เวอร์ชัน 0.2 รุ่นทดลองก่อนเปิดตัว** เวอร์ชันแรกทำงานบน Windows 11 ของผู้ฟังหนึ่งคน
ผ่าน ASIO (Behringer UMC204HD และ SMSL D200): WAV 24/192 ออกไปเป็น ASIO 32 บิต
โดยไม่แปลงและไม่สะดุด และการควบคุมจากมือถือใช้งานได้ นี่คือรายงานเส้นทางสัญญาณ
จากตัวเครื่องเล่นเอง ยังไม่มีใครจับเอาต์พุตมาเทียบทีละบิต ฟีเจอร์ใหม่ของ 0.2
มีเทสต์ครอบคลุมแล้ว แต่ยังไม่เคยรันบน Windows ภาพหน้าจอมาจากเวอร์ชันแรก
จากบิลด์สำหรับพัฒนาบน macOS กับคลังเพลงตัวอย่าง — ยังไม่มีแถบความดัง
และสวิตช์ L/R

บิลด์ Windows เป็นไฟล์ zip: แตกไฟล์แล้วเปิด `Elfton Player.exe` หรือรัน
`install.ps1` ที่แนบมาเพื่อเพิ่มทางลัดในเมนู Start ไม่มีอะไรอื่นถูกติดตั้ง
สำหรับ ASIO ต้องติดตั้งไดรเวอร์ของ DAC ก่อน ถ้าไม่มี เครื่องเล่นจะเสนอ WASAPI
รีโมตในมือถือตอนนี้มีเฉพาะ Android (APK) เวอร์ชัน iOS เสร็จในโค้ดแล้ว
แต่ยังไม่มีบิลด์สาธารณะ

เอนจินเขียนด้วย Go บน FFmpeg (LGPL, ลิงก์แบบไดนามิก) ส่วนอินเทอร์เฟซใช้ Flutter
