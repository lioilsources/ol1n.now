Elfton Player ହେଉଛି Windows 11 ପାଇଁ ଏକ ଲୋକାଲ ସଂଗୀତ ପ୍ଲେୟାର, ଯାହାର କେବଳ ଗୋଟିଏ
ପ୍ରାଥମିକତା: USB DAC ପର୍ଯ୍ୟନ୍ତ ଠିକ୍ ସେହି ସାମ୍ପଲ ପହଞ୍ଚୁ, ଯାହା ଫାଇଲରେ ଅଛି।
ସିଗନାଲର ପଥ ହେଉଛି **ଫାଇଲ → ଡିକୋଡର → RAM → ASIO → DAC**। ନା ଭଲ୍ୟୁମ,
ନା ଇକ୍ୱାଲାଇଜର, ନା ରିସାମ୍ପଲିଂ, ନା ଷ୍ଟ୍ରିମିଂ। ଭଲ୍ୟୁମ କନଭର୍ଟର କିମ୍ବା
ଆମ୍ପ୍ଲିଫାୟାରରେ ସେଟ୍ କର।

### କ'ଣ କରିପାରେ

- **Bit-perfect ଆଉଟପୁଟ** ASIO ଦ୍ୱାରା, କିମ୍ବା ଏକ୍ସକ୍ଲୁସିଭ ମୋଡରେ WASAPI ଦ୍ୱାରା। ଟ୍ରାକ
  ପାଖରେ ପୂରା ଶୃଙ୍ଖଳ ଦେଖାଯାଏ (`FLAC 24/96k → 32-bit · bit-perfect`), ଆଉ ସିଗନାଲରେ
  କିଛି ବି ହସ୍ତକ୍ଷେପ ହେବା ମାତ୍ରେ ସବୁଜ ବିନ୍ଦୁ ଲିଭିଯାଏ।
- **ମେମୋରୀରୁ ପ୍ଲେବ୍ୟାକ।** ପୂରା ଟ୍ରାକ RAM ରେ ଡିକୋଡ ହୁଏ, ତେଣୁ ବଜାଇବା ସମୟରେ ଡିସ୍କ
  କାମ କରେ ନାହିଁ; ପରବର୍ତ୍ତୀ ଟ୍ରାକ ଆଗରୁ ଲୋଡ ହୋଇଯାଏ ଆଉ **ବିନା ବିରତିରେ** ଆଗକୁ ବଢ଼େ।
- **ସାମ୍ପଲ ପର୍ଯ୍ୟନ୍ତ ସଠିକ A-B ଲୁପ**, ଯେଉଁଥିରେ ପଏଣ୍ଟଗୁଡ଼ିକୁ ମିଲିସେକେଣ୍ଡ ହିସାବରେ ଘୁଞ୍ଚାଇହେବ — କୌଣସି
  ଅଂଶର ଅଭ୍ୟାସ ପାଇଁ କିମ୍ବା ରେକର୍ଡିଂର ଦୁଇଟି ସ୍ଥାନର ତୁଳନା ପାଇଁ।
- **ଫୋଲ୍ଡର ଅନୁସାରେ ଲାଇବ୍ରେରୀ**: ଡିରେକ୍ଟୋରୀ ଗଛ ଠିକ୍ ଯେମିତି ତୁମ ଡିସ୍କରେ ଅଛି, କଭର,
  ସର୍ଚ୍ଚ, କ୍ୟୁ, ପସନ୍ଦ, ହିଷ୍ଟ୍ରି, M3U ପ୍ଲେଲିଷ୍ଟ, CUE ସହ ଗୋଟିଏ ଫାଇଲରେ ଆଲବମ,
  LRC ରୁ ସିଙ୍କ ହୋଇଥିବା ଗୀତର ଶବ୍ଦ।
- **FLAC, ALAC, WAV, AIFF, MP3, AAC, Ogg ଆଉ DSD** (ନେଟିଭ, DoP, କିମ୍ବା PCM କୁ ରୂପାନ୍ତର)।
- **Mono (L+R)/2** ସିଗନାଲରେ ଏକମାତ୍ର ହସ୍ତକ୍ଷେପ ଭାବେ, ସବୁବେଳେ ସ୍ପଷ୍ଟ ଭାବେ ଚିହ୍ନିତ।
- **L ଆଉ R ବଟନ** କେବଳ ଗୋଟିଏ ସ୍ପିକର ବଜାଏ ଆଉ ଅନ୍ୟଟିକୁ ମ୍ୟୁଟ କରେ। ମୋନୋ ଚାଲୁ ଥିଲେ
  ଦୁଇଟିରେ ଏକା ଜିନିଷ ବାଜେ, ତେଣୁ ଚେୟାରରେ ବସି ଫୋନରେ ତୁରନ୍ତ ସିଷ୍ଟମର ବାମ
  ଆଉ ଡାହାଣ ପାର୍ଶ୍ୱର ତୁଳନା କରିପାରିବ (କେବୁଲ, ଉପାଦାନ); ମୋନୋ ବିନା ରେକର୍ଡିଂର କେବଳ ବାମ
  କିମ୍ବା କେବଳ ଡାହାଣ ଚ୍ୟାନେଲ ବାଜେ।
- **ଟ୍ରାକର ଲାଉଡନେସ ଭଳି ଅଙ୍କା ହୋଇଥିବା ସିକ ବାର** ୱିଣ୍ଡୋର ପୂରା ଓସାରରେ: ଶାନ୍ତ
  ଆରମ୍ଭ ଦେଖାଯାଏ ଆଉ ଗୋଟିଏ କ୍ଲିକରେ ଡେଇଁହୁଏ।
- **ଟ୍ରାକରେ ହୃଦୟ** ଆଉ „କେବଳ ପସନ୍ଦ“ ଫିଲ୍ଟର ସିଧା ଆଲବମରେ।
- **ତିନୋଟି ଥିମ**: ଡାର୍କ, କଳା ଆଉ ଲାଇଟ।
- **ଫୋନରେ ରିମୋଟ**: Elfton Remote ଘର ନେଟୱର୍କରେ QR କୋଡ ଦ୍ୱାରା ଯୋଡ଼ିହୁଏ
  ଆଉ କମ୍ପ୍ୟୁଟରର ୱିଣ୍ଡୋ ଯାହା କରେ ସେସବୁ କରିପାରେ।

### ପ୍ଲେବ୍ୟାକ ମୋଡ

ଚାହିଁଲେ ବଜାଇବା ସମୟରେ ପାୱାର ପ୍ଲାନ ବଦଳାଏ, USB ସିଲେକ୍ଟିଭ ସସପେଣ୍ଡ ଆଉ କୋର ପାର୍କିଂ
ବନ୍ଦ କରେ, ଆଉ ଶେଷରେ ସବୁକିଛି ପୂର୍ବ ଅବସ୍ଥାକୁ ଫେରାଏ। ସଚ୍ଚୋଟ ଭାବେ କହିଲେ: ଆସିଙ୍କ୍ରୋନସ USB DAC
ରେ ଘଣ୍ଟା କନଭର୍ଟର ସମ୍ଭାଳେ, ତେଣୁ ଏହି ପରିବର୍ତ୍ତନଗୁଡ଼ିକର ଧ୍ୱନି ଉପରେ କୌଣସି ମାପିବା ଯୋଗ୍ୟ ପ୍ରଭାବ
ନାହିଁ। ଏଗୁଡ଼ିକ ବୈକଳ୍ପିକ, ପ୍ରତ୍ୟେକଟି ଲଗରେ ଲେଖାହୁଏ ଆଉ ଏଥିରୁ କୌଣସିଟିର ଆବଶ୍ୟକତା ନାହିଁ।

ସେହି କଥା Bug head ପ୍ଲେୟାରରୁ ନିଆଯାଇଥିବା „ରୀତି“ ପାଇଁ ବି ପ୍ରଯୁଜ୍ୟ, ଯାହା ସେଟିଂସରେ ଅଛି
ଆଉ ଡିଫଲ୍ଟ ଭାବେ ବନ୍ଦ: ସଂଗୀତକୁ RAM ରେ ଲକ କରିବା, ଟ୍ରାକ ଲୋଡ ହେବା ପରେ ବିରତି,
ଆଉ ପ୍ଲେୟାର ସହ ନିଜର ସହାୟକ ପ୍ରୋଗ୍ରାମ (ଉଦାହରଣ ସ୍ୱରୂପ MinorityClean)
ଚଳାଇବା। MinorityClean ଅନ୍ତର୍ଭୁକ୍ତ ନୁହେଁ।

### ସ୍ଥିତି

**ସଂସ୍କରଣ 0.2, ପ୍ରି-ରିଲିଜ।** ପ୍ରଥମ ସଂସ୍କରଣ ଜଣେ ଶ୍ରୋତାଙ୍କ ପାଖରେ Windows 11 ରେ ASIO ଦ୍ୱାରା
ଚାଲିଥିଲା (Behringer UMC204HD ଆଉ SMSL D200): WAV 24/192 କୌଣସି ରୂପାନ୍ତର ଓ କୌଣସି
ଡ୍ରପଆଉଟ ବିନା 32-ବିଟ ASIO ଭାବେ ବାହାରିଲା, ଆଉ ଫୋନରୁ ନିୟନ୍ତ୍ରଣ କାମ କରେ।
ଏହା ସିଗନାଲ ପଥ ବିଷୟରେ ସ୍ୱୟଂ ପ୍ଲେୟାରର ରିପୋର୍ଟ; ଆଉଟପୁଟକୁ ଏପର୍ଯ୍ୟନ୍ତ କେହି କ୍ୟାପଚର
କରି ବିଟ-ପରେ-ବିଟ ତୁଳନା କରିନାହାନ୍ତି। ସଂସ୍କରଣ 0.2 ର ନୂଆ ସୁବିଧାଗୁଡ଼ିକ ଟେଷ୍ଟ ଦ୍ୱାରା କଭର,
କିନ୍ତୁ Windows ରେ ଏପର୍ଯ୍ୟନ୍ତ ଚାଲିନାହିଁ। ସ୍କ୍ରିନସଟଗୁଡ଼ିକ ପ୍ରଥମ ସଂସ୍କରଣର,
ନମୁନା ଲାଇବ୍ରେରୀ ସହ macOS ଡେଭଲପମେଣ୍ଟ ବିଲ୍ଡରୁ — ଲାଉଡନେସ ବାର
ଆଉ L/R ସୁଇଚ ସେଥିରେ ଏପର୍ଯ୍ୟନ୍ତ ନାହିଁ।

Windows ବିଲ୍ଡ ଏକ zip: ଏହାକୁ ଅନଜିପ କରି `Elfton Player.exe` ଚଳାଅ, କିମ୍ବା ସାଙ୍ଗରେ ଥିବା
`install.ps1` ଚଳାଅ, ଯାହା ଷ୍ଟାର୍ଟ ମେନୁରେ ସର୍ଟକଟ ଯୋଡ଼େ। ଆଉ କିଛି
ଇନଷ୍ଟଲ ହୁଏ ନାହିଁ। ASIO ପାଇଁ କନଭର୍ଟରର ଡ୍ରାଇଭର ଇନଷ୍ଟଲ ଥିବା ଦରକାର; ତାହା ବିନା
ପ୍ଲେୟାର WASAPI ପ୍ରଦାନ କରେ। ଫୋନ ପାଇଁ ରିମୋଟ ଏବେ କେବଳ Android (APK) ପାଇଁ;
iOS ସଂସ୍କରଣ କୋଡରେ ପ୍ରସ୍ତୁତ, କିନ୍ତୁ ଏହାର କୌଣସି ସାର୍ବଜନୀନ ବିଲ୍ଡ ନାହିଁ।

ଇଞ୍ଜିନ FFmpeg ଉପରେ Go ରେ ଲେଖାଯାଇଛି (LGPL, ଡାଇନାମିକ), ଇଣ୍ଟରଫେସ Flutter ରେ।
