Elfton Player 是一款 Windows 11 本機音樂播放器，只有一個目標：
送進 USB DAC 的取樣，必須和檔案裡的一模一樣。
訊號路徑是 **檔案 → 解碼器 → 記憶體 → ASIO → DAC**。沒有音量調整，
沒有等化器，沒有重新取樣，沒有串流。音量請在 DAC 或
擴大機上調整。

### 功能

- **位元完美輸出**，透過 ASIO 或獨占模式的 WASAPI。曲目旁會顯示整條鏈路
  （`FLAC 24/96k → 32-bit · bit-perfect`），只要有任何東西動到訊號，
  綠點就會熄滅。
- **從記憶體播放。** 整首曲目解碼進記憶體，播放時硬碟不運作；下一首會預先載入，
  **無縫接續**。
- **取樣級精準的 A-B 循環**，循環點可依毫秒微調 —— 適合練習某段樂句，
  或比較錄音中的兩個位置。
- **依資料夾整理的音樂庫**：目錄樹和你硬碟上的一樣，封面、搜尋、播放佇列、
  最愛、歷史紀錄、M3U 播放清單、附 CUE 的單檔專輯、LRC 同步歌詞。
- **FLAC、ALAC、WAV、AIFF、MP3、AAC、Ogg 和 DSD**（原生、DoP 或轉換為 PCM）。
- **單聲道 (L+R)/2** 是對訊號唯一的更動，而且一律清楚標示。
- **L 和 R 按鈕** 只讓一顆喇叭出聲，另一顆靜音。開啟單聲道時兩邊播放相同內容，
  坐在沙發上用手機就能馬上比較音響系統的左右兩側（線材、零件）；不開單聲道時，
  只播放錄音的左聲道或右聲道。
- **依曲目音量繪製的進度列** 橫跨整個視窗寬度：安靜的前奏一眼就看得到，
  點一下就能跳過。
- **每首曲目都有愛心**，專輯內可直接用「只看最愛」篩選。
- **三種主題**：深色、純黑和淺色。
- **手機遙控**：Elfton Remote 透過家用網路掃描 QR 碼配對，
  電腦視窗能做的它都能做。

### 播放模式

可依需求在播放時切換電源計畫，關閉 USB 選擇性暫停和核心停駐，結束後全部還原。
老實說：對非同步 USB DAC 而言，時脈由 DAC 掌控，這些調整對聲音沒有可測量的影響。
它們都是選用的，每一項都會寫入記錄，而且沒有一項是必要的。

沿用自 Bug head 播放器的「儀式」也一樣，它們在設定裡，預設關閉：
把音樂鎖定在記憶體中、載入曲目後暫停片刻、隨播放器一起啟動你自己的輔助程式
（例如 MinorityClean）。MinorityClean 不包含在內。

### 現況

**0.2 版，預先發行。** 第一個版本在一位聽眾的 Windows 11 上透過 ASIO
（Behringer UMC204HD 和 SMSL D200）執行：WAV 24/192 以 32 位元 ASIO 輸出，
沒有轉換、沒有斷音，手機遙控也正常。這是播放器自己對訊號路徑的回報；
目前還沒有人擷取輸出並逐位元比對。0.2 的新功能已有測試涵蓋，
但還沒在 Windows 上執行過。截圖來自第一個版本，
是用範例音樂庫的 macOS 開發版擷取的 —— 上面還沒有音量列和 L/R 切換。

Windows 版是一個 zip：解壓縮後執行 `Elfton Player.exe`，或執行附帶的
`install.ps1`，它會在開始功能表加入捷徑。除此之外不會安裝任何東西。
使用 ASIO 需要先安裝 DAC 的驅動程式；沒有驅動程式時播放器會提供 WASAPI。
手機遙控目前只有 Android 版（APK）；iOS 版程式碼已完成，但還沒有公開版本。

引擎以 Go 撰寫，建立在 FFmpeg（LGPL，動態連結）之上，介面使用 Flutter。
