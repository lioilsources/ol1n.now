---
tagline: Bit-perfect плеер для USB DAC — файл, RAM, ASIO и ничего между ними
---
Elfton Player — плеер локальной музыки для Windows 11 с единственным приоритетом:
чтобы в USB DAC попадали ровно те сэмплы, которые есть в файле.
Путь сигнала: **файл → декодер → RAM → ASIO → DAC**. Никакой регулировки
громкости, никакого эквалайзера, никакого ресемплинга, никакого стриминга.
Громкость регулируется на преобразователе или усилителе.

### Что умеет

- **Bit-perfect вывод** через ASIO или WASAPI в эксклюзивном режиме. Рядом
  с треком видна вся цепочка (`FLAC 24/96k → 32-bit · bit-perfect`), а зелёная
  точка гаснет в тот же момент, когда что-либо вмешивается в сигнал.
- **Воспроизведение из памяти.** Трек целиком декодируется в RAM, поэтому диск
  во время воспроизведения не работает; следующий трек загружается заранее
  и идёт **без паузы**.
- **Петля A-B с точностью до сэмпла** со сдвигом точек по миллисекундам — чтобы
  отработать фрагмент или сравнить два места записи.
- **Библиотека по папкам**: дерево каталогов в том виде, в каком оно у тебя
  на диске, обложки, поиск, очередь, избранное, история, плейлисты M3U, альбомы
  одним файлом с CUE, синхронизированные тексты из LRC.
- **FLAC, ALAC, WAV, AIFF, MP3, AAC, Ogg и DSD** (нативно, DoP или преобразование в PCM).
- **Моно (L+R)/2** как единственное вмешательство в сигнал, всегда заметно обозначенное.
- **Кнопки Л и П** оставляют играть только одну колонку и глушат другую.
  С включённым моно в обеих звучит одно и то же, так что прямо из кресла
  с телефона можно сразу сравнить левую и правую сторону системы (кабели,
  компоненты); без моно играет только левый или только правый канал записи.
- **Ползунок в виде громкости трека** на всю ширину окна: тихое вступление
  видно, и его можно пропустить одним кликом.
- **Сердечко у трека** и фильтр «только избранное» прямо в альбоме.
- **Три темы**: тёмная, чёрная и светлая.
- **Пульт в телефоне**: Elfton Remote подключается по QR-коду через домашнюю
  сеть и умеет всё то же, что и окно на компьютере.

### Режим воспроизведения

По желанию во время воспроизведения переключает схему электропитания, запрещает
временное отключение USB-порта и парковку ядер, а по окончании всё возвращает.
Честно: у асинхронного USB DAC тактирование держит сам преобразователь, так что
эти настройки не оказывают измеримого влияния на звук. Они необязательны, каждая
записывается в лог, и ни одна из них не нужна.

То же касается «ритуалов», позаимствованных у плеера Bug head, которые есть
в настройках и по умолчанию выключены: блокировка музыки в RAM, пауза после
загрузки трека и запуск собственной вспомогательной программы (например,
MinorityClean) вместе с плеером. MinorityClean в комплект не входит.

### Статус

**Версия 0.2, предварительный выпуск.** Первая версия работала на Windows 11
у одного слушателя через ASIO (Behringer UMC204HD и SMSL D200): WAV 24/192
выходил как 32-битный ASIO без преобразования и без выпадений, а управление
с телефона работает. Это отчёт самого плеера о пути сигнала; выход пока никто
не записал и не сравнил бит в бит. Новинки версии 0.2 покрыты тестами,
но на Windows ещё не запускались. Скриншоты сделаны с первой версии,
с девелоперской сборки для macOS с демонстрационной библиотекой — полосы
с графиком громкости и переключателя Л/П на них ещё нет.

Сборка для Windows — это zip: распакуй и запусти `Elfton Player.exe` или
запусти приложенный `install.ps1`, который добавит ярлык в меню «Пуск».
Больше ничего не устанавливается. Для ASIO должен быть установлен драйвер
преобразователя; без него плеер предложит WASAPI. Пульт для телефона пока
есть только для Android (APK); версия для iOS готова в коде, но публичной
сборки нет.

Движок написан на Go поверх FFmpeg (LGPL, динамическая линковка), интерфейс — на Flutter.
