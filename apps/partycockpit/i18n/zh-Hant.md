PartyCockpit 把派對上的電視變成一場現場秀。賓客掃描螢幕上的 QR Code，用手機傳送各種風格的自拍、貼上牆的留言、小段舞蹈和相機即時畫面。你在平板上掌控 **Cockpit**：看到誰傳了什麼，審核通過，並切換螢幕上正在播放的內容。手機不用裝 App，有瀏覽器就行。

### 沒有審核，什麼都上不了螢幕

每張照片、每則留言、每段舞蹈都要等你放行。原圖永遠不會上螢幕，只有換上新風格的照片。按下 **PANIC** 按鈕，螢幕立刻切回安全的投影片輪播，並關閉即時相機和麥克風。

### 場景

- **賓客藝廊**：維梅爾、動漫或漫畫風格的自拍，搭配會眨眼、會微笑的動態肖像
- **留言牆**：每則留言都是手寫效果，字型來自 HandWrittenStickers，賓客在手機上自選字跡
- **舞池**：賓客選一段舞，幾分鐘後就在螢幕上跳起來
- **直播**：最多九支手機當相機，在螢幕上以格狀排列
- **字幕**：對著麥克風說話，螢幕上就會出現逐字稿和翻譯
- **著色器中場**和 **StyleMap**：隨音樂節奏呼吸的畫面
- **派對單元**：用今晚的照片做成漫畫，對話框裡是賓客的留言
- 壓軸的 **Recap**：當晚的一切，再加上一個讓賓客下載照片的 QR Code

### 中場遊戲

抽籤選出玩家，大家來玩 **Kruh**：每個人用手指在手機上拖動球拍，守住自己的那段弧。球會隨音樂節奏加速，最後還有命的人獲勝。

### 跟著節拍

所有場景都隨節奏律動：節奏來自播放音樂、接受賓客點歌的 DJfy，來自螢幕旁的麥克風，或來自你在 Cockpit 裡敲出的拍子。

### 派對盒子

PartyCockpit 在派對網路中的一台電腦上執行：電視旁的筆電或迷你電腦，或是一台 Raspberry Pi 5。下載 Windows 或 Linux 套件，執行後在瀏覽器裡打開螢幕即可。手機透過 Wi-Fi 連線，什麼都不用安裝。照片和留言只存在那台電腦上，派對結束一週後會自動刪除。風格轉換和舞蹈需要 GPU 伺服器，沒有的話只能模擬效果。
