tagline: Приложение для знакомств без слов, где ты инопланетянин и пары складываются по настроению
---
AlienMatch делает всё наоборот по сравнению с обычными приложениями для знакомств. Никаких отретушированных селфи, никакого описания, никаких свайпов.

### Инопланетное лицо

Фото профиля делается только вживую на камеру, а приложение собирает из него симметричное «инопланетное» лицо из двух одинаковых половинок. Какая из них твоя, выбираешь ты. В мир уходит только она, оригинал никогда не покидает телефон. Её нельзя украсть из Инстаграма или найти обратным поиском по картинке.

### Без слов

Вместо возраста поколение, вместо текста значки: чего тебе хочется (кофе, прогулка, вино…) и кого ты ищешь. Единственное, что ты пишешь, это ник.

### Радар по настроению

Раз в день ты отправляешь короткий сигнал о том, как у тебя дела. Радар показывает людей планетами на звёздной карте и подбирает пары по настроению и по тому, куда оно движется. Двух людей, которым сейчас плохо, он не соединит никогда. Тот, кто на подъёме, может стать маяком для того, кто хочет подбодрить других.

### Места без слежки

В профиль можно добавить до восьми мест: свою остановку, трамвай, кафе или факультет. Приложение никогда не получает твою геопозицию по GPS. Общее место показывается, только если оно есть у нескольких людей.

### Статус

В разработке. Бэкенд и первая версия приложения готовы, но в магазинах его пока нет. Без рекламы и без слежки. Только для взрослых (18+).
