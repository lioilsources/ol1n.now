tagline: Stiker dari tulisan tanganmu sendiri
---
Ketik teks, lalu aplikasi menyusunnya karakter demi karakter dari huruf tulisan
tangan — dan menyimpannya sebagai PNG transparan yang bisa kamu kirim sebagai
stiker.

Set pertama adalah tulisan tangan anak sungguhan: Laurinka mengisi templat A4,
templat itu difoto, lalu sebuah alat memotong 160 karakter darinya, termasuk
semua diakritik bahasa Ceko. Siapa pun bisa mencetak templat yang sama dan
mengisinya. Set pindaian kedua, huruf sambung Jessie 1, menyambungkan huruf
dalam satu kata dengan satu goresan pena, seperti tulisan sambung sungguhan.

Selain itu ada lebih dari delapan puluh set lain dalam tiga kategori — tulisan
tangan, kaligrafi, dan tipografi — serta set anak-anak dan set bahan: gelembung,
plastisin, roti jahe, neon. Kamu bisa mengganti set langsung di editor, dan teks
disusun di garis dasar dengan spasi proporsional, jadi tidak terlihat seperti
guntingan.

### Preset dan emoji

Preset adalah set beserta gayanya: spasi, tinggi baris, goyangan garis dasar,
ukuran dan kemiringan huruf. Bawaannya Rapi, Biasa, Pesan Kilat, dan Kacau;
lainnya ada di paket (Surat Cinta, Tulisan Kue, Pesan Anak, Papan Neon…).
Pengaturanmu sendiri bisa disimpan sebagai preset baru. Saat dibuka lagi,
aplikasi ingat di mana kamu berhenti.

Ke pesan, kamu bisa menambahkan salah satu dari 41 stiker emoji gambar tangan
yang bergoyang pelan. Dengan emoji itu, stiker disimpan sebagai GIF animasi yang
juga bisa dikirim lewat aplikasi pesan.

### Gratis, paket tambahan

Editor, preset bawaan, ekspor PNG dan GIF, emoji, dan huruf sambung itu gratis.
Yang berbayar nanti adalah konten tambahan — paket huruf bertema dengan preset
sendiri (Tulisan Tangan, Kaligrafi, Poster & Tulisan, Untuk Anak, Bahan) — dan
menyimpan preset sendiri. Set yang terkunci bisa kamu coba di editor;
pembayaran baru muncul saat menyimpan. Paket akan dijual di App Store dan Google
Play, tempat aplikasi ini belum tersedia. Di versi Windows dan Linux semuanya
terbuka.

Dua bagian: alat berbasis Go yang membuat set karakter dari pindaian templat
atau dari font, dan aplikasi Flutter yang menyusun teks dari set itu (repo
`HandWrittenStickers`).
