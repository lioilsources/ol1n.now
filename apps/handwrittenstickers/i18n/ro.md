tagline: Stickere din propriul tău scris de mână
---
Scrie un text, iar aplicația îl compune caracter cu caracter din litere scrise de
mână — și îl salvează ca PNG transparent, pe care îl poți trimite ca sticker.

Primul set este scris de copil adevărat: Laurinka a completat un șablon A4, care a
fost fotografiat, iar un instrument a decupat din el 160 de caractere, inclusiv
toate diacriticele limbii cehe. Oricine poate tipări și completa același șablon.
Al doilea set scanat, scrisul cursiv Jessie 1, leagă literele dintr-un cuvânt
dintr-o singură trăsătură de stilou, ca un scris legat adevărat.

Pe lângă ele sunt peste optzeci de alte seturi în trei categorii — scris de mână,
caligrafie și tipografie — plus seturi pentru copii și din materiale: balon,
plastilină, turtă dulce, neon. Schimbi setul direct în editor, iar textul este
așezat pe linia de bază cu spațiere proporțională, așa că nu pare decupat.

### Presetări și emoji

O presetare este un set împreună cu un stil: spațiere, înălțimea rândului,
oscilația liniei de bază, mărimea și înclinarea literelor. Incluse sunt Îngrijit,
Obișnuit, Bilet rapid și Haos, iar altele vin cu pachetele (Scrisoare de dragoste,
Inscripție pe tort, Bilet de copil, Firmă neon…). Îți poți salva setările ca
presetare nouă. La următoarea pornire, aplicația își amintește unde ai rămas.

La mesaj poți adăuga unul dintre cele 41 de stickere emoji desenate, care se
leagănă ușor. Cu el, stickerul se salvează ca GIF animat, pe care îl pot trimite
și aplicațiile de mesagerie.

### Gratuit, pachete în plus

Editorul, presetările incluse, exportul PNG și GIF, emoji și literele legate sunt
gratuite. Se va plăti pentru conținutul suplimentar — pachete tematice de scrisuri
cu presetări proprii (Scrisuri de mână, Caligrafie, Afișe și inscripții, Pentru
copii, Materiale) — și pentru salvarea presetărilor proprii. Poți încerca un set
blocat în editor; plata apare abia la salvare. Pachetele se vor cumpăra din App
Store și Google Play, unde aplicația nu este încă disponibilă. În versiunea pentru
Windows și Linux totul este deblocat.

Două părți: un instrument în Go care face dintr-o scanare a șablonului sau dintr-un
font un set de caractere și o aplicație în Flutter care compune textul din ele
(repo `HandWrittenStickers`).
