ミームのテンプレートを6〜15秒の縦型ショート動画に変えるコマンドラインツールです。元のミームはジョークの構成の下敷きとして使うだけで、出力に含まれることは決してありません。代わりにオリジナルのキャラクターが演じます。

プロンプトやシードではキャラクターの一貫性を保てないため、画像はショートごとに生成しません。承認済みの *キャラクター × 感情* ライブラリとして一度だけ作ります。Kiro、Mei、Taro、Yuki の4人が、それぞれ得意げな顔から疲れ果てた顔まで12の表情を持っています。

ショートはその後 `classify → storyboard → generate → animate → compose → qa` のパイプラインを通ります。各ステップは個別に保存され、オプションのハッシュをキーにしているので、再実行はコストゼロ、テキストを変えても必要な部分だけが再計算されます。ジョークは LLM が書くか、手動で入力します。字幕は Go で直接レンダリングします。

出力は 1080×1920、H.264、30 fps、ラウドネス −14 LUFS で、映像とメタデータの両方に「AI generated」の表示が入ります。

今のところローカルでのみ動作し、リリース版はないため、ここでダウンロードできるものはありません。
Go で書かれており、画像は自前のマシン上の FLUX.1-schnell が生成します。
