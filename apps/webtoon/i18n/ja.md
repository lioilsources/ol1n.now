Toonfork（仮称 Webtoon）は、インターネットがなくても使える縦読みマンガリーダーです。インストール直後から15作品を無料で読めます。アカウントも登録も不要です。物語は自前のGPUサーバーで作られています。言語モデルが脚本を書き、画像モデルがコマを描き、テキストの入った吹き出しはリーダー側で最後に重ねます。そのため、画像を作り直さずに文章だけを直せます。

子ども向け5作品の完成ストリップはサブページ「Strips」に、話の終わりに選択肢があるゲームの流れはサブページ「Gamebook」にあります。

### リーダー

物語は、吹き出し、心の声、叫び、効果音の入ったコマが1本に長く連なったもので、親指で上から下へスクロールして読みます。一部のコマは短いループで動き出します。窓を伝う雨、水面の光、髪をなびかせる風。話の終わりには何が選ばれたかと **次の話** ボタンが表示されます。最終話の後には **おわり** と、次に読む物語のおすすめが出ます。

### ゲームブック

ゲームブックでは、物語の行方をあなたが決めます。各パートの終わりに次の展開を選ぶと、物語が分岐します。アプリは今いる場所、通ってきた道、見つけたエンディングを覚えていて、ルートマップにはすでに訪れた場所だけが表示されます。最初からやり直すことも、一歩戻ることもできます。ゲームブックは無料です。子ども向けには **サラと くろい かんむり**、大人向けにはカウンセリングルームを舞台にした室内劇 **黙ることを学ぶ**、**頭上の鋼鉄の空**、**灰色になった花咲く草原** などがあります。ドラマは重いテーマを扱うため、キッズプロフィールでは表示されません。

ベータ版として分岐エディターがあります。どの選択肢にも自分だけの続きを追加でき、ゲームブックの画像から組み立てて吹き出しを書けます。作った分岐はすぐに遊べて、共有機能で作者に送ることもできます。サーバーは使いません。

### パック

追加パックで最大50作品が加わります。**ロマンス**（大人向けの軽やかな恋愛もの、過激な描写なし）、**キッズ**、**スーパーヒーロー**。パックは購入後にダウンロードされ、オフラインで読めます。一度の購入で、今後出るパックも含めてすべてが解放されます。

### プロフィールと保護者ロック

初回起動時に **キッズ** か **大人** のプロフィールを選びます。キッズプロフィールでは、ライブラリでもストアでもロマンスとドラマが表示されません。購入や大人プロフィールへの切り替えは、九九の問題を使った保護者ロックで毎回確認されます。

### 12言語

物語、ゲームブック、リーダーの表示は12言語に対応しています。チェコ語、英語、ドイツ語、フランス語、イタリア語、ポーランド語、ブラジルポルトガル語、日本語、韓国語、ベトナム語、ロシア語、ウクライナ語です。吹き出しの言語は設定で切り替えられます。

### プライバシー

アカウントなし、広告なし、トラッキングなし。Toonfork は個人データを収集しません。購入したものは端末が記憶し、購入の復元は設定から行えます。

## Studio：物語ができるまで

同じアプリのもう一つの顔が、作者向けの Studio です。作者は世界を作ります。設定（ロア）、キャラクター、場所、そしてすべての物語が通らなければならない正史（カノン）です。Studio ではインタラクティブに遊ぶこともできます。話の終わりに読者がキャラクターの次の行動を選ぶか、自分の言葉で書くと、その選択から次の話が生まれます。自由入力の文章はまずモデレーションを通ります。子ども向けの世界ではより厳しく、迷ったときは却下します。このページのスクリーンショットは Studio のものです。

### ワールドエディター

作者はアプリの **作成** タブを使います。

- **基本：** タイトル、あらすじ、トーン、言語、対象（子ども向け、13歳以上、大人向け）、公開範囲、そして世界全体に適用される画風。
- **ロアとカノン：** 世界のルール、勢力、順序が固定されたカノンの節目、そしてガードレール、つまり起きてはいけないこと。
- **キャラクターとロケーション：** 自分の言葉で書いた説明。そこから LLM が画像モデル用の固定 booru タグを提案します。モデルが知らないタグは WD14 の語彙に基づいて除外され、残りを作者が調整します。
- **キャラクターシート：** 白背景に描かれたキャラクターの4つのバリエーション。タグに最も合うものが参照画像になります。
- **概要：** キャンペーン、読者がどこで止まったか、どの選択肢を選んだか、カノンのどこまで進んだか。

### モデル

- **脚本とモデレーション：** vLLM 経由の Qwen3.6-35B-A3B。キャラクターとロケーションにはタグを提案し、各話には絵コンテ（6〜8コマ、2〜3の選択肢、自由入力欄）を書きます。その後、バリデーターがキャラクター、場所、世界のルールをチェックします。
- **コマ：** ComfyUI 経由の SDXL。標準は NoobAI-XL eps 1.1、2つ目の画風は Hassaku XL (Illustrious) 3.4 です。人間のキャラクターを描くのはこれらのモデルだけです。
- **動くコマ：** Wan 2.2 が完成したコマを1〜3秒のループにします。1話につき動くコマは最大2つです。
- **コンテンツチェック：** WD14 タガー（SmilingWolf/wd-swinv2-tagger-v3）。すべてのコマをチェックし、対象に応じて破棄して新しいシードで描き直します。子ども向けでは、体にぴったりした服や露出の多い服も却下します。同じタガーで、コマの中のキャラクターがデザインどおりかも測ります。

キャラクターの同一性はタグだけで保っています。IP-Adapter も用意してありますが、最初の測定ではむしろ画像を崩しがちでした。モデルは1つのカットに人間のキャラクターを2人収めると、髪型や服を取り違えてしまいます。そのため子ども向けの物語では、キャラクターごとに別のコマを使っています。

### 画風

画風は名前の付いたプリセットで、チェックポイント、サンプラー、ステップ数、CFG、美的タグからなります。作者は世界全体に対して一度だけ選びます。**clean_webtoon_noartist** はフラットな色と整った線、**hassaku_soft** は柔らかな陰影とパステルカラーが特徴です。ビジュアルでは同じ話を両方の画風で並べて見られます。

### 現状

Toonfork はアルファ版です。Android 版は Google Play で公開中、macOS 版のビルドは GitHub からダウンロードでき、App Store は準備中です。Studio は自前のバックエンド（Go と Postgres のジョブキュー）でのみ動作し、一般公開はしていません。画像も文章も自前の GPU サーバーで作られています。

スクリーンショットは、ローカルのバックエンドにつないだ Studio のウェブ版をスマホの幅で撮ったものです。そこに写っている第2話はまだ脚本だけで、コマは描画待ちです。ソースコードは [github.com/lioilsources/Webtoon](https://github.com/lioilsources/Webtoon) にあります。
