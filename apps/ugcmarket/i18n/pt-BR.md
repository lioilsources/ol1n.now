O Ol1n Market é uma loja de modelos 3D de acessórios para avatares em
[market.ol1n.com](https://market.ol1n.com): capacetes, mochilas, bolsas e mais.
Cada modelo está pronto para o Roblox Studio. Tem até 4.000 triângulos, o tamanho
certo e textura própria. O pacote também traz um GLB mais detalhado para outras ferramentas 3D.

Os modelos são feitos pela UGC Factory e conferidos por uma pessoa antes de entrarem na loja.
Parte do catálogo é grátis, é só entrar com seu e-mail. Vendas pagas com cartão
e bitcoin estão chegando. Cada download vem com uma licença e um README com
o passo a passo para o Roblox Studio.

Um guia passo a passo com capturas de tela (em inglês): [Guide for Roblox Studio](ugcmarket-guide.html).

O Ol1n Market não é afiliado, endossado nem patrocinado pela Roblox Corporation.
“Roblox” é uma marca registrada da Roblox Corporation e é usada aqui apenas para descrever
compatibilidade.
