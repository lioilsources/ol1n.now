O Ol1n Market é uma loja de modelos 3D de acessórios para avatares em
[market.ol1n.com](https://market.ol1n.com): capacetes, mochilas, malas e muito mais.
Cada modelo está pronto para o Roblox Studio. Tem até 4000 triângulos, o tamanho
certo e textura própria. O pacote inclui também um GLB mais detalhado para outras ferramentas 3D.

Os modelos são feitos pela UGC Factory e verificados por uma pessoa antes de serem publicados.
Parte do catálogo é gratuita, basta iniciar sessão com o teu e-mail. Os pagamentos com cartão
e bitcoin estão a caminho. Cada transferência inclui uma licença e um README com
os passos para o Roblox Studio.

Um guia passo a passo com capturas de ecrã (em inglês): [Guide for Roblox Studio](ugcmarket-guide.html).

O Ol1n Market não é afiliado, apoiado nem patrocinado pela Roblox Corporation.
«Roblox» é uma marca registada da Roblox Corporation e é usada aqui apenas para descrever
a compatibilidade.
